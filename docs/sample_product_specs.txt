Local Assistant Product Specs

Product name: Local Assistant
Version: 1.0

Purpose:
Local Assistant is a document question-answering tool with local retrieval and Groq answer generation.
It helps teams search their own text documents and see which chunks supported an answer.

Key features:
- FastAPI backend for queries
- Streamlit frontend for chatting
- FAISS vector search for semantic retrieval
- BM25-style keyword scoring for sparse retrieval
- Optional query rewrite after weak retrieval
- Source citations and latency metrics with each answer

Technical constraints:
- Supports text documents only
- Requires an existing FAISS index before startup
- Uses normalized embeddings for cosine-style similarity
- Sends retrieved context to Groq for answer generation

Recommended usage:
The best results come from concise documents with clear headings and repeated terminology.
If retrieval is weak, the optional query rewrite step can search a second time.
